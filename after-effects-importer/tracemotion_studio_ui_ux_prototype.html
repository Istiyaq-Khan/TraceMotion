From "Airplane Cockpit" to Effortless Studio

Every redundant widget, manual scrollbar, and physics formula from the original ScriptUI panel was audited. Below is what was deleted, automated behind the scenes, or unified.

Manual Scrollbar + ▲ / ▼ Buttons
scrollBar, btnScrollUp, btnScrollDown
 Deleted Replaced by responsive 3-tab navigation when narrow (<540px) and a 2-column grid when wide (≥540px). Eliminates 16px dead scrollbar chrome. win.onResize toggles tabbed stack vs 2-col row
Asset Format Radio Buttons
PNG (Universal 2020+) vs Vector SVG (AE 2024+)
 Automated Completely removed from UI. Script automatically uses crisp Vector SVG in AE 2024+ (v24.0+) and 512px Retina PNG in AE 2020–2023. preferSvg = (parseFloat(app.version) >= 24.0)
Separate Video & JSON File Rows
2 labels, 2 edittext paths, 2 Browse... buttons
 Unified Single Capture Source card. Selecting a video auto-pairs <video>.cursor.json and shows a green sync badge with sample count & discreet Relink button. new File(f.fsName + ".cursor.json")
"Vector Shape (Procedural)" Dropdown Option
5th item in cursorDropdown
 Automated Removed from user-facing style cards. Kept strictly as an automatic silent fallback if cursor image assets are missing on disk. Fallback inside if (!assetFile.exists)
Raw Spring Physics Float (0.67)
smoothSlider (10–150) + smoothInput
 Translated Replaced with 4 human Motion Feel buttons: Natural (0.67), Snappy (0.32), Silky (1.15), and Raw (0.00). Maps directly to options.cursorSmoothing
Physics Math Checkboxes
PI/18 Tilt Physics, 350ms Half-Sine 84%
 Simplified All 4 smart behaviors default to ON and are tucked into a collapsed-by-default Fine-Tune Physics accordion with plain-English labels. dynamicCursorStates, swayAmount, createClickBounce, enableMotionBlur
Ripple VFX Dropdown + Hex Textbox
fxDropdown + colorInput (#2563EB)
 Unified Merged into 1 compact row of 4 clickable color swatches (#2563EB, #FFFFFF, #10B981, #F59E0B) + an Off toggle. Sets clickEffect & clickEffectColor
45-Item Text Dropdown for Wallpapers
bgDropdown + separate cursorCanvas & bgCard
 Unified Merged separate cursor & background boxes into one interactive Live Composition Preview Stage, paired with 3×2 visual backdrop tiles + full 39-wallpaper picker. Maps to RECORDLY_WALLPAPERS & BACKGROUND_PRESETS
[?] Help Button & Blocking alert() Modals
helpBtn + completion popup dialog
 Deleted Replaced by contextual helpTip tooltips, an inline non-blocking status bar, and an Update Active Rig mode when a TraceMotion comp is already open. statusTxt.text + updateTraceMotionRig()
